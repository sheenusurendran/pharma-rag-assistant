# Pharma RAG Assistant

## Overview
A learning and portfolio project exploring Retrieval-Augmented Generation (RAG) for pharmaceutical information.

The project uses Google's Gemini API, sentence embeddings, semantic similarity, reranking, and ChromaDB to explore retrieval and generation workflows.

## Project Files
- `app.py` — application entry point
- `pharma_knowledge.txt` — pharmaceutical knowledge source
- `storeabcdrugs.py` — knowledge storage component
- `retrievalabcdrugs.py` — retrieval component
- `rag_test.py` — RAG testing
